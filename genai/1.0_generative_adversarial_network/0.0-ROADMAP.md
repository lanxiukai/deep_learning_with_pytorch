# Generative Adversarial Network Learning Roadmap

This directory orders the lessons by the main idea added at each stage. The
SN-GAN, SAGAN, and BigGAN sequence uses aligned CelebA faces at 64x64, with
the binary Smiling attribute keeping conditional generation easy to inspect.

## 1. Foundations

1. `1.0_gan.py` introduces the original adversarial objective.
2. `2.0_dcgan_anime_face.py` and `2.1_dcgan_pokemon.py` introduce convolutional
   image generators and discriminators.
3. `3.0_wgan_gp.py` replaces probability classification with a Wasserstein
   critic and gradient penalty.
4. `4.0_conditional_gan.py` introduces label conditioning, followed by
   checkpoint evaluation in `4.1_conditional_gan_evaluation.py`.

## 2. Translation Models

1. `5.0_pix2pix.py` introduces paired image-to-image translation.
2. `5.1_pix2pix_evaluation.py` evaluates the trained pix2pix generator.
3. `5.2_cycle_gan.py` introduces unpaired translation and cycle consistency.
4. `5.3_cycle_gan_evaluation.py` evaluates both CycleGAN directions.

## 3. SN-GAN to BigGAN

1. `6.0_sn_gan.py` introduces projection SN-GAN: conditional BatchNorm in G,
   a projection discriminator, discriminator-only spectral normalization,
   and hinge loss.
2. `6.1_sagan.py` reuses that hierarchy, adds spectral normalization to G,
   widens D's residual branches, and inserts non-local attention at 16x16.
3. `6.2_biggan.py` adds one shared class embedding, five hierarchical latent
   chunks, orthogonal initialization,
   modified orthogonal regularization, and two-to-one updates.
4. `6.3_sn_sagan_biggan_evaluation.py` compares eight held-out CelebA faces
   per attribute label with eight fresh generated faces. Paired generated
   rows share latent vectors to show the effect of changing the label.
   Missing checkpoints are reported and skipped.

The common 4x4-to-64 generator and 64-to-4 discriminator use a base width of
64. Model classes also support 128x128, while these lessons default to 64x64.
Prepare aligned CelebA with `tool_scripts/download_dataset.py --dataset celeba`.
The loader reads `data/celeba/list_eval_partition.csv` and
`list_attr_celeba.csv`, joins labels by image filename, and uses all 162,770
images in the official training split. The Smiling attribute maps -1 to class
0 (not smiling) and +1 to class 1 (smiling), giving 84,690 and 78,080 training
images respectively. The larger aligned dataset provides many examples of a
consistent subject while preserving categorical conditional BatchNorm and
projection discrimination.

Preprocessing center-crops the aligned images to 178x178, resizes them to
64x64, and normalizes RGB values to [-1, 1]. Training adds horizontal flips;
evaluation uses a deterministic transform and the separate 19,867-image
validation split. The [official CelebA page](https://mmlab.ie.cuhk.edu.hk/projects/CelebA.html)
describes the dataset and its attributes. No auxiliary recognition network or
additional augmentation loss is needed by these lessons.

All three lessons keep an exponential moving average (EMA, decay 0.999) of G
for sampling. The live generator supplies adversarial updates; `generator.pth`
stores the EMA and `online_generator.pth` stores the live weights. This shared
sampling stabilizer helps reduce the large changes between nearby checkpoints.
SAGAN and BigGAN refresh their EMA BatchNorm and spectral-normalization buffers
with 32 forward-only noise batches before each epoch's preview and checkpoint.
This avoids using live-model statistics with averaged parameters, which caused
overly dark SAGAN samples in a local trial. Calibration changes no parameters
and uses a separate random generator. PyTorch also documents the need to
[refresh BatchNorm statistics for averaged models](https://docs.pytorch.org/docs/stable/generated/torch.optim.swa_utils.AveragedModel.html).

| Lesson | Main algorithm settings | Teaching training budget |
|---|---|---|
| SN-GAN | z=128, G/D LR=1e-4/2e-4, Adam `(0, 0.9)`, 1:1 updates | 2 attribute classes, batch D/G=64, and 8 epochs |
| SAGAN | z=128, G/D LR=1e-4, Adam `(0, 0.9)`, 1:1 updates | 2 attribute classes, batch 64, and 4 epochs |
| BigGAN | z=120, shared embedding=128, G/D LR=1e-4, Adam `(0, 0.9)`, 2:1 updates, EMA=0.999 | 2 attribute classes, batch 64, and 8 epochs |

At batch 64, each epoch contains 2,543 full batches. An epoch is one pass over
the training split; the budgets may differ after each model's visual review.

These are teaching implementations, not metric reproductions. They preserve
the architectural comparisons while exposing batch, epoch,
worker, precision, data, and output paths through the CLI. They do not claim
the papers' FID or Inception Score without the papers' distributed compute and
evaluation protocols. Primary references are the authors' [projection SN-GAN
repository](https://github.com/pfnet-research/sngan_projection), the [SAGAN
paper](https://proceedings.mlr.press/v97/zhang19d.html), and the [BigGAN
paper](https://arxiv.org/abs/1809.11096). Inspect fresh random samples for
recognizable facial structure, variation within each class, and the effect of
the Smiling label. These visual checks are suitable for a teaching run; they
do not establish a benchmark score.
Fresh runs reset their output directory. Resuming preserves checkpoints and
allows a longer epoch budget with the same model and optimization settings.

## 4. Style-Based Generation

1. `7.0_progan.py` introduces progressive growing, fade-in transitions,
   equalized learning rates, PixelNorm, minibatch standard deviation, and
   WGAN-GP with critic drift regularization.
2. `7.1_stylegan.py` keeps the progressive schedule and adds the paper's
   eight-layer mapping network, W space, a learned constant, AdaIN, stochastic
   noise, style mixing, and truncation through a moving `w_avg`.
3. `7.2_stylegan2.py` trains the full 128x128 network from the beginning. It
   replaces AdaIN with weight modulation/demodulation, retains the original
   one-convolution 4x4 block and overlapping W-slot routing, uses
   skip-connected RGB outputs, and adds lazy R1, path-length regularization,
   and generator EMA.
4. `7.3_progan_stylegan_stylegan2_evaluation.py` saves focused comparisons for
   fixed latent samples, stochastic noise, per-model style-mixing matrices,
   truncation through each style generator's learned `w_avg`, and Z-versus-W
   latent interpolation.

ProGAN and StyleGAN start with a stabilized 4x4 network. Every transition to
8x8, 16x16, 32x32, 64x64, and 128x128 has a fade-in phase followed by
stabilization. Each phase consumes 400 kimg and writes one phase-boundary
checkpoint. StyleGAN2 instead trains one full 128x128 network for 5,000 kimg
and checkpoints at data-epoch boundaries. This keeps checkpoint scheduling
outside the algorithms' inner update loops. All three use the official CelebA
training split, center-crop the aligned 178x218 inputs, and downsample them to
the active resolution. They use compact single-GPU batch schedules, pure
PyTorch filtered resampling rather than custom fused CUDA kernels, and
image-count-based generator EMA.

The evaluation reuses the same standard-normal `z` tensors across independently
trained generators only to fix random conditions. The samples do not have
model-to-model semantic correspondence. Noise, mixing, and truncation figures
use fixed styles or fixed layer noise where needed so each changed factor stays
explicit. Evaluation inference is chunked at the 128x128 training microbatch,
and style mixing separates 4-32 structure styles from 64-128 detail styles.
