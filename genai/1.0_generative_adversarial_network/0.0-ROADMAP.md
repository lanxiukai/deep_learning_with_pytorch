# Generative Adversarial Network Learning Roadmap

This directory orders the lessons by the main idea added at each stage. The
SN-GAN, SAGAN, and BigGAN sequence uses the 10-class Imagenette dataset at
128x128, keeping large-scale GAN ideas practical for an algorithm course.

## 1. Foundations

1. `1.0_gan.py` introduces the original adversarial objective.
2. `2.0_dcgan_anime_face.py` and `2.1_dcgan_pokemon.py` introduce convolutional
   image generators and discriminators.
3. `3.0_wgan_gp.py` replaces probability classification with a Wasserstein
   critic and gradient penalty.
4. `4.0_conditional_gan.py` introduces label conditioning, followed by
   checkpoint evaluation in `4.1_conditional_gan_evaluation.py`.

## 2. Translation Models

1. `5.0_pix2pix.py` introduces paired image-to-image translation.
2. `5.1_pix2pix_evaluation.py` evaluates the trained pix2pix generator.
3. `5.2_cycle_gan.py` introduces unpaired translation and cycle consistency.
4. `5.3_cycle_gan_evaluation.py` evaluates both CycleGAN directions.

## 3. SN-GAN to BigGAN

1. `6.0_sn_gan.py` follows the authors' 128x128 projection SN-GAN: conditional
   BatchNorm in G, a projection discriminator, discriminator-only spectral
   normalization, and five D updates per G update.
2. `6.1_sagan.py` reuses that hierarchy, adds spectral normalization to G,
   widens D's residual branches, inserts non-local attention at 32x32, and
   introduces TTUR with one-to-one updates.
3. `6.2_biggan.py` moves attention to 64x64 and adds one shared class
   embedding, six hierarchical latent chunks, orthogonal initialization,
   modified orthogonal regularization, two-to-one updates, and generator EMA.
4. `6.3_sn_sagan_biggan_evaluation.py` compares one Imagenette reference with a
   fresh conditional sample for all ten class indices and skips missing
   checkpoints.

The common 4x4-to-128 generator and 128-to-4 discriminator channel schedule
uses a base width of 64. This is the public SN-GAN and SAGAN width and BigGAN's
reported baseline width, rather than BigGAN's more expensive ch=96 scale.
Shared preparation downloads Imagenette-320, center-crops the long edge,
performs the bilinear resize once, and stores a resumable
`data/imagenette-128` JPEG cache. Sources whose short edge is below 128 or
whose decoded dimensions exceed 50 million pixels are excluded and recorded.
Training loaders retain optional horizontal flipping; SN-GAN also retains
uniform dequantization.

| Lesson | Paper-oriented settings retained | Single-RTX-5090 adaptation |
|---|---|---|
| SN-GAN | z=128, batch D/G=16/32, Adam 2e-4 `(0, 0.9)`, 5:1 updates | 10 classes and 20 epochs; final paper LR decay omitted |
| SAGAN | z=128, ch=64, G/D LR=1e-4/4e-4 `(0, 0.9)`, 1:1 updates | 10 classes, batch 16, and 20 epochs |
| BigGAN | z=120, shared embedding=128, ch=64, G/D LR=5e-5/2e-4 `(0, 0.999)`, 2:1 updates, EMA=0.9999 | 10 classes, batch 8, and 20 epochs; no distributed BatchNorm machinery |

These are teaching implementations, not metric reproductions. They preserve
the architectural and optimization comparisons while exposing batch, epoch,
worker, precision, data, and output paths through the CLI. They do not claim
the papers' FID or Inception Score without the papers' distributed compute and
evaluation protocols. Primary references are the authors' [projection SN-GAN
repository](https://github.com/pfnet-research/sngan_projection), the [SAGAN
paper](https://proceedings.mlr.press/v97/zhang19d.html), and the [BigGAN
paper](https://arxiv.org/abs/1809.11096). The local source-size filtering and
JPEG cache are practical input-pipeline choices, not paper reproduction
details, and slightly change the training distribution.

## 4. Style-Based Generation

1. `7.0_progan.py` introduces progressive growing, fade-in transitions,
   equalized learning rates, PixelNorm, minibatch standard deviation, and
   WGAN-GP with critic drift regularization.
2. `7.1_stylegan.py` keeps the progressive schedule and adds the paper's
   eight-layer mapping network, W space, a learned constant, AdaIN, stochastic
   noise, style mixing, and truncation through a moving `w_avg`.
3. `7.2_stylegan2.py` trains the full 128x128 network from the beginning. It
   replaces AdaIN with weight modulation/demodulation, retains the original
   one-convolution 4x4 block and overlapping W-slot routing, uses
   skip-connected RGB outputs, and adds lazy R1, path-length regularization,
   and generator EMA.
4. `7.3_progan_stylegan_stylegan2_evaluation.py` saves focused comparisons for
   fixed latent samples, stochastic noise, per-model style-mixing matrices,
   truncation through each style generator's learned `w_avg`, and Z-versus-W
   latent interpolation.

ProGAN and StyleGAN start with a stabilized 4x4 network. Every transition to
8x8, 16x16, 32x32, 64x64, and 128x128 has a fade-in phase followed by
stabilization. Each phase consumes 400 kimg and writes one phase-boundary
checkpoint. StyleGAN2 instead trains one full 128x128 network for 5,000 kimg
and checkpoints at data-epoch boundaries. This keeps checkpoint scheduling
outside the algorithms' inner update loops. All three use the official CelebA
training split, center-crop the aligned 178x218 inputs, and downsample them to
the active resolution. They use compact single-GPU batch schedules, pure
PyTorch filtered resampling rather than custom fused CUDA kernels, and
image-count-based generator EMA.

The evaluation reuses the same standard-normal `z` tensors across independently
trained generators only to fix random conditions. The samples do not have
model-to-model semantic correspondence. Noise, mixing, and truncation figures
use fixed styles or fixed layer noise where needed so each changed factor stays
explicit. Evaluation inference is chunked at the 128x128 training microbatch,
and style mixing separates 4-32 structure styles from 64-128 detail styles.
