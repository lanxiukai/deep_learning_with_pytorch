# Generative Adversarial Network Learning Roadmap

This directory orders the lessons by the main idea added at each stage. The
SN-GAN lesson uses CIFAR-10's native 32x32 resolution, while the attention and
BigGAN lessons retain their compact 64x64 teaching backbone.

## 1. Foundations

1. `1.0_gan.py` introduces the original adversarial objective.
2. `2.0_dcgan_anime_face.py` and `2.1_dcgan_pokemon.py` introduce convolutional
   image generators and discriminators.
3. `3.0_wgan_gp.py` replaces probability classification with a Wasserstein
   critic and gradient penalty.
4. `4.0_conditional_gan.py` introduces label conditioning, followed by
   checkpoint analysis in `4.1_conditional_gan_analysis.py`.

## 2. Translation Models

1. `5.0_pix2pix.py` introduces paired image-to-image translation.
2. `5.1_pix2pix_evaluation.py` evaluates the trained pix2pix generator.
3. `5.2_cycle_gan.py` introduces unpaired translation and cycle consistency.
4. `5.3_cycle_gan_evaluation.py` evaluates both CycleGAN directions.

## 3. SN-GAN to BigGAN

1. `6.0_sn_gan.py` establishes a native-32x32 conditional residual baseline
   with spectral normalization, projection discrimination, and hinge losses.
2. `6.1_sagan.py` uses the compact 64x64 backbone and replaces its middle
   identity mappings with self-attention on 16x16 features.
3. `6.2_biggan.py` adds shared class embeddings, conditional BatchNorm,
   hierarchical latent chunks, modified orthogonal regularization, and
   two-time-scale learning rates.
4. `6.3_sn_sagan_biggan_evaluation.py` uses matching labels and latent vectors
   to compare all three generators and two BigGAN truncation thresholds in one
   titled image grid.

All three training scripts use one progress bar across the complete run, save
titled fixed-noise class grids after every epoch, and write independent-y loss
panels that keep discriminator, generator, and BigGAN regularization scales
visually separate.

These scripts are compact teaching implementations. They preserve the central
mechanisms but do not reproduce the datasets, batch sizes, channel widths, or
compute budgets of the original large-scale papers.

## 4. Style-Based Generation

1. `7.0_progan.py` introduces progressive growing, fade-in transitions,
   equalized learning rates, PixelNorm, minibatch standard deviation, and
   WGAN-GP with critic drift regularization.
2. `7.1_stylegan.py` keeps the progressive schedule and adds a mapping network,
   W space, a learned constant, AdaIN, stochastic noise, style mixing, and
   truncation through a moving `w_avg`.
3. `7.2_stylegan2.py` trains the full 32x32 network from the beginning. It
   replaces AdaIN with weight modulation/demodulation, uses skip-connected RGB
   outputs, and adds lazy R1, path-length regularization, and generator EMA.
4. `7.3_progan_stylegan_stylegan2_evaluation.py` compares fixed latent samples,
   stochastic noise, style mixing, and truncation in one sectioned figure.

ProGAN and StyleGAN start with a stabilized 4x4 network. Every transition to
8x8, 16x16, and 32x32 has a fade-in phase followed by stabilization. Their
global progress bars are sized from the actual epochs and loader lengths in
the complete schedule; StyleGAN2 instead trains one full 32x32 network for the
entire run. All three use pure PyTorch filtered resampling rather than custom
fused CUDA kernels.

The evaluation reuses the same standard-normal `z` tensors across independently
trained generators only to fix random conditions. The samples do not have
model-to-model semantic correspondence.
