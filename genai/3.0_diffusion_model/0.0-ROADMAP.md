# Diffusion Model Lessons

These scripts are algorithm lessons, not a scheduler catalog or a production
training framework. They keep the probability path, prediction target,
conditioning rule, reverse update, and endpoint convention explicit. Repeated
components are split along the same mathematical boundaries as the lessons:

- `diffusion_ddpm.py` owns discrete VP schedules and DDPM/DDIM transitions;
- `diffusion_score_sde.py` owns continuous score dynamics and their solvers;
- `diffusion_unet.py` owns the shared time-conditioned backbone.

`dl_utils/diffusion/ddpm.py` remains only as a compatibility import facade. Dataset
loops and each algorithmic objective stay visible in the lesson that uses them.

## 1. Learning Order

| Lesson | Visible increment | Generation path |
|---|---|---|
| `1.0_ddpm.py` | Closed-form VP noising and denoising regression; optional cosine schedule, prediction parameterization, and class dropout | Training only, with short DDIM previews |
| `1.1_ddpm_sampling.py` | Hold the denoiser fixed and change only the reverse transition | Full-step stochastic DDPM versus shortened DDIM |
| `2.0_score_sde.py` | Replace discrete indices with continuous VP time and predict the score | Reverse SDE versus probability-flow ODE |
| `3.0_kl_autoencoder.py` | Build the weak-KL, perceptual continuous first stage only when entering LDM | Mean/sample reconstruction, latent scaling, and frozen encode/decode identity |
| `3.1_latent_diffusion.py` | Freeze the KL autoencoder and move the same DDPM objective to its scaled 8x8 latent grid | Latent DDPM/DDIM followed by one decoder pass |
| `4.0_edm.py` | Separate preconditioning, training-noise distribution, loss weighting, sigma grid, and solver | Euler or Heun probability-flow integration |

The baseline supports epsilon, clean-image, diffusion-v, and score outputs.
Score regression uses sigma-squared weighting so its loss is directly
comparable to epsilon regression. A conditional CIFAR-10 run learns an explicit
null class through condition dropout; sampling combines the null and class
branches with the documented classifier-free-guidance convention.

The cosine schedule is retained as the compact Improved-DDPM schedule
increment. Learned reverse variance and the hybrid likelihood objective are not
folded into the baseline: they would change the output contract from `C` to
`2C`, require a separate endpoint likelihood convention, and obscure the fixed
variance DDPM/DDIM comparison. Predictor-corrector and annealed-Langevin
samplers are likewise extensions of the score sampler rather than new training
models.

## 2. Stage Boundaries

Pixel DDPM, Score-SDE, and EDM consume CIFAR-10 images normalized to `[-1, 1]`.
Latent Diffusion instead requires the completed first-stage checkpoint from
`genai/3.0_diffusion_model/3.0_kl_autoencoder.py`. This placement is
intentional: the VAE route ends at VQGAN, while this autoencoder's complete
teaching identity includes the downstream LDM interface. Latent Diffusion loads
that checkpoint's latent channel count and dataset-level scale, freezes every
autoencoder parameter, and stores the same interface identity, configuration,
and scale in the diffusion checkpoint. Sampling refuses a mismatched first
stage.

Typical entry points are:

```bash
python genai/3.0_diffusion_model/1.0_ddpm.py
python genai/3.0_diffusion_model/1.1_ddpm_sampling.py --sampler both
python genai/3.0_diffusion_model/2.0_score_sde.py --mode both
python genai/3.0_diffusion_model/3.0_kl_autoencoder.py
python genai/3.0_diffusion_model/3.1_latent_diffusion.py --mode both
python genai/3.0_diffusion_model/4.0_edm.py --mode both
```

DDPM generation evaluates all training timesteps. DDIM may use a shorter
subsequence; `eta=0` is deterministic for a fixed initial noise tensor. The
reverse SDE is stochastic, while a fixed probability-flow solver and EDM's
deterministic ODE path are deterministic for a fixed initial state.

## 3. Resource and Verification Contract

Defaults use 32x32 CIFAR-10, a roughly 12 M-parameter pixel U-Net, and no
full-resolution attention. The default latent U-Net works on 8x8 states. These
settings are intended for one GeForce RTX 4070 Ti with 12 GB; reduce batch size
before changing the algorithm if memory is tighter. Mixed precision,
compilation, distributed training, hidden hyperparameter search, and metric
pipelines are deliberately outside these lessons.

Every lesson accepts `--smoke-test`. These CPU checks cover parameterization
identities, one backward pass, frozen-stage gradient boundaries, deterministic
sampler contracts, trajectory shapes, and finite outputs. They do not establish
convergence or image quality. A real comparison must keep the checkpoint,
initial noises, conditions, and evaluation sample count fixed while reporting
NFE and sampler settings.
